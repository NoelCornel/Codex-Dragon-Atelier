# Codex Dragon Atelier：可读性重建与成年角色实施方案

## A. 当前截图问题诊断

### **Q 版暗色模式（background-q-dark.png）**
1. **图像模糊问题**：192×208px 源被放大至 280px，放大率 145.8%，在常规 DPR 下已超过 1:1 显示阈值，边缘抗锯齿被拉伸；
2. **过度滤镜叠加**：`brightness(.94) saturate(.68)` + `opacity .56` 三重削弱，Q 版本身线条细，深色背景下紫色轮廓（#9a8ba8 系）与 #252422 背景对比仅约 2.2:1，龙角、服饰细节完全融入背景；
3. **中央文字对比不足**：正文 #ebe8e2 在 #252422 上约 12.8:1，但标题「今天想一起完成什么？」字重未增强，13px 无加粗在深灰背景 + 低透明度人物干扰下视觉存在感弱；
4. **侧栏可读性**：侧栏文字 #ebe8e2，但实际渲染字重 400，中文 13px 笔画细，与背景 #252422 虽对比度充足，但视觉穿透力不足；
5. **输入框 placeholder**：「随心输入」文字几乎不可见，推测实际合成色接近 #6c665e，在 #2e2b28 composer 背景上对比度约 1.8:1，严重低于 4.5:1 标准。

### **Q 版亮色模式（background-q-light.png）**
1. **图像失去立体感**：同样放大模糊问题，但 `brightness(.96) saturate(.62)` 在浅背景下将紫色服饰、阴影全部漂白，人物变成扁平剪影；
2. **紫色元素完全丧失边界**：紫眼、服饰紫边与 #e8e4dc 背景几乎无对比，#7d6993 accent 在高亮度下饱和度被进一步压制，无任何描边补偿；
3. **文字对比崩溃**：正文 #2d2a27 在 #e8e4dc 上对比度约 10.5:1，数值尚可，但因背景过亮 + 人物淡化干扰，实际阅读舒适度远低于数值预期；
4. **toast 与 popup 白块**：顶部「已导入 浅色 主题」通知仍为纯白背景，未被 token 覆盖；
5. **输入框 placeholder**：#6c665e 在 #f2efea 上对比度约 3.5:1，低于 4.5:1，且视觉比暗色更不明显。

### **正常立绘暗色模式（background-portrait-dark.png）**
1. **人物严重模糊**：937×1678 与 941×1672 原始分辨率本已不足（按 1080p 高度计算每边仅覆盖窗口 1/3），再施加 `opacity .50` + `brightness(.94) saturate(.68)`，五官、龙翼细节完全丧失；
2. **中央遮挡与对比冲突**：人物占据画面 18%–82% 水平区间，`linear-gradient` 中央遮罩仅 48% 不透明度，不足以在输入框、对话气泡区域建立清晰前景；左右人物头部位于屏幕 1/4 与 3/4 位置，长对话时文字直接叠压在灰化的脸部与服饰纹理上；
3. **输入框与底部容器无实心背景**：composer #2e2b28 有 1px 描边但背景半透明特性未被纠正，实际渲染时底部人物裙摆、龙尾透过输入框可见，placeholder 与图像纹理叠加导致完全不可读；
4. **紫色轮廓问题同 Q 版**：服饰、龙角边界完全融入 #252422 背景，无独立描边，两个角色视觉上是一团模糊的灰紫色块；
5. **缺失视觉层次**：人物、渐变、内容三层全为半透明叠加，没有任何一层建立明确的"前景容器"角色。

### **正常立绘亮色模式（background-portrait-light.png）**
1. **人物过曝与漂白**：`brightness(.96) saturate(.62)` + `opacity .54` 在浅背景下将白发、白裙、浅紫服饰全部溶解为统一的 #e8e4dc 色阶，只剩轮廓线勉强可见；
2. **中央文字几乎不可见**：#2d2a27 文字在 #e8e4dc 背景 + 透明人物干扰下，实际对比度降至约 6:1（因人物灰度层削弱），长句阅读极困难；
3. **输入框背景过淡**：#f2efea composer 与 #e8e4dc 背景对比度仅 1.15:1，输入区域几乎无视觉边界，placeholder #6c665e 在此基础上完全消失；
4. **白块残留**：与 Q 版相同，原生 popup、settings 面板未被完全覆盖；
5. **两个人物无区分度**：灰白一体，无法通过视觉判断左右角色差异。

**白块排查 SOP**：
1. 在 DevTools 中定位白色元素，检查 computed background-color；
2. 查找元素 class/role，优先使用语义选择器（`[role=alert]`）而非 class 匹配；
3. 若为内联样式，使用 `!important` 覆盖；
4. 若为伪元素（`::before/::after`），单独处理；
5. 避免 `html * {}` 全局规则，会破坏语法高亮、危险按钮等语义色。

## E. 成年角色布局与尺寸方案

### **1. 左右站位与相对尺寸**

**参考 DSH 规则但独立实施**：
- **成熟角色（左）**：长裙、开放手势、头部位于屏幕垂直 30–35% 位置（眼睛约 400–450px from top，1080p 参考）；
- **年轻角色（右）**：短裙、记事本、头部位于屏幕垂直 32–37% 位置（略低于左侧，营造对话感而非平行展示）；
- **两者头顶高度差**：不超过 60px（约 5.5% 屏幕高度），通过姿态（左侧略微前倾、右侧直立）和服装（裙摆长度）体现成熟度差异，避免机械缩放；
- **视线交汇**：两者眼睛朝向屏幕中央 48–52% 水平位置，头部转向角度 15–20°。
