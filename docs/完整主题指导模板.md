# Codex Dragon Atelier 完整主题指导模板

## 1. 设计方向选择与色彩策略

### 1.1 最终选定：B 温润石灰

**核心配色**：
- 浅色底 `#e8e4dc`（象牙纸、暖米白）
- 深色底 `#252422`（中性炭灰、微暖调）
- 强调色：淡紫 + 亚光金

**选择理由**：
1. **材质语言最一致**：呼应白龙的象牙裙、珍珠光泽、灰白主色调，不依赖高饱和噱头
2. **低饱和高级感**：米白与中性灰建立层次，典雅克制，符合"现代简约、有质感"
3. **阅读舒适性**：浅色不刺眼（94亮度vs A的96），深色有温度（非纯黑）
4. **清晰区别DSH**：不用海蓝/冷色宫殿，保持白龙识别度
5. **淡紫与旧金作为点缀**：强调色占比克制，不抢主材质

**放弃A/C原因**：
- A矿物雾紫：全面灰紫调单一，缺乏暖度与材质对比
- C墨青灰玉：冷色深度偏离象牙/珍珠感，更接近玉石而非织物

### 1.2 设计语言关键词
珍珠象牙、纸感织物、淡紫点缀、亚光金线、中性温润、低亮度层次。

**禁止**：高饱和粉紫、整屏纯白、冷蓝科技感、浮夸装饰、全屏遮挡。

## 2. 核心目标与约束边界

### 2.1 产品定位
为 Windows Codex 桌面端打造 **GPT 龙娘工坊（Codex Dragon Atelier）** 完整主题系统，达到 DeepSeek Harness Maid Atelier 的系统完整度：统一语义 token、全组件状态、成对明暗配色、响应式装饰、可恢复架构。

### 2.2 角色与版本
**同一位白发龙娘的双姿态**，无主次、无模型绑定：
- 白发、灰白龙角、淡紫眼睛、象牙/灰白裙装、龙翼单尾、少量旧金装饰
- **轻量版（Lite）**：仅配色系统，无人物装饰
- **全量Q版（Chibi）**：192×208px双姿态，上移至聊天区中部
- **全量正常立绘（Portrait）**：左937×1678、右941×1672，严格等高、近似等大

### 2.3 视觉体量纠正（强制执行）
**双姿态必须等高、近似等大**，不再采用左大右小、1.6:1或主次设计。Q版相同尺寸并上移至聊天区域中部横线，避开底部输入框。正常立绘统一高度基准，各自保持宽高比。

### 2.4 技术约束（不可越过）
1. 不修改 WindowsApps、app.asar、官方EXE；通过主题分享码+独立窗口CDP实现
2. 保留原生字体设置、菜单层级、输入逻辑、系统辅助功能
3. 舞台仅在 `main[data-app-shell-main-surface]` 第一子节点，`absolute/z-index:0/pointer-events:none`
4. 选择器用可见语义属性 `[data-da-part]`，不依赖CSS哈希类
5. 仅使用已授权图像资源，背景优先CSS渐变
6. 窄屏<700px、低高度≤420px、侧面板挤占时响应退让或隐藏

## 5. 字体颜色与视觉层级

### 5.1 字体策略
**沿用客户端设置**：字号、字体族、中英文fallback由用户设置负责，主题不强制覆盖。

**可选建议**（仅文档说明）：
- Windows简中：Microsoft YaHei UI, Segoe UI, sans-serif
- 代码：Consolas, Cascadia Code, monospace

### 5.2 视觉层级通过颜色实现

| 层级 | token | 字重建议 | 用途 |
|------|------|---------|------|
| 标题 | `--da-text-primary` | 600–700 | 对话标题、区块标题 |
| 正文 | `--da-text-primary` | 400 | 消息正文、段落 |
| 次要 | `--da-text-secondary` | 400 | 时间戳、说明文字 |
| 辅助 | `--da-text-tertiary` | 400 | caption、label |
| 占位符 | `--da-text-placeholder` | 400 | input placeholder |
| 禁用 | `--da-text-disabled` | 400 | disabled状态 |
| 链接 | `--da-text-link` | 400 | 超链接 |
| 按钮文字 | `--da-text-primary` / onAccent | 500 | 按钮内文字 |

### 5.3 对比度要求
实施者需工具验证：
- 正文与底色 ≥7:1（AAA）
- 次要/辅助文字 ≥4.5:1（AA）
- 禁用文字 ≥3:1（最低可读）
- 链接与底色 ≥4.5:1（AA）
- 按钮文字与按钮底 ≥4.5:1（AA）

**不编造已通过数值**，由实施者现场测量。

## 6. 背景与装饰方案

### 6.1 材质语言
**珍珠象牙**：浅色用暖米白、纸感，深色用中性炭灰。<br>
**淡紫点缀**：极克制的径向渐变，不大面积铺满。<br>
**亚光金线**：仅底部ornament细节，不用于大面积装饰。

### 6.2 CSS渐变背景（无图像方案）

**主区域底** `[data-da-part="main"]`：

```css
background-image: radial-gradient(ellipse 42% 58% at 18% 94%, rgba(125,105,147,0.06), transparent 100%);
```

```css
}

  }
```
```css
}
```
