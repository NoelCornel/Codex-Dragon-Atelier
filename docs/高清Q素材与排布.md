## 实际采用

采用已公开高清原图做背景去除，保留其脸、服装、手势和星仪关系，而非重新设计身材。imagegen透明结果仍为941×1672，四角alpha为0；没有声称前景像素完全未变。第一遍仅有低alpha色噪，实际明暗窗口缩小显示后未看到明显亮边；第二遍精修产生少数高alpha彩色像素，反而未采用。原图、候选均留存，不将alpha存在当作全部边缘完美证明。

两侧用同一幅高清图作对称构图：左侧不翻转、角色及星仪向右；右侧CSS翻转、角色及星仪向左。是同姿态朝内试排，不虚称两张独立动作或两种年龄的Q图。Q版与正常成年双气质版单独提供。

首页按实际聊天区域和输入边界计算，最大宽300 CSS px，会话上限260；当前1608×1044窗口、DPR1.25时实际每幅265.754 CSS px。原像素上限仍保留，但不再受192px桌宠帧限制。位于聊天区域纵向中部的同一横线，完整图盒底部至少距输入框28px；聊天列不足700px/高度不足时隐藏。没有设置横跨桌面的窗口层。

## 验证与边界

两种模式实际匿名预览逐张查看，脸/眼/服装、双翼、单尾、饰件及星仪可辨，输入与主标题分层。132个实际命中点不由舞台接收事件，文字/背景/原生字体未被截图遮盖重绘。两版输入、菜单、设置、恢复及真实滚轮、24类模拟回归及DPR1/1.25/1.5/2逻辑检查另记在VALIDATION。

这仍为实验性背景去除衍生；原作者人物图的画风比上一轮自行生成Q更接近参考，但最终审美取舍由用户判断。没有承诺alpha在任意原始像素级放大都无噪点，不使用插值放大低分辨率帧冒称高清。

本轮滚轮检查曾因固定500ms等待失败。关闭主题的对照同样出现延迟，最终原生/有主题均能滚动；一次CDP输入及观察序列总用时约6.0s/5.1s，包含协议与调用等待，不等于纯用户界面延迟测量。后续验收逐次读取实际位移，避开嵌套工具输出滚动区；功能检查不证明不存在性能问题，也不证明历史桌面遮挡已修复。
