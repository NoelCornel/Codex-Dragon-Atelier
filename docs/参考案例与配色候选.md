# 参考案例与配色候选

用户最新确认：明暗主题是亮度与阅读层级，不限定黑白色相。DSH 女仆工坊提供完整度和前后关系的参考；本项目取现代简约、低饱和、典雅有质感的方向，亮度比 DSH 收敛。角色原设不变，双姿态等大，Q 版上移。

## 成熟设计参考

- [Radix Themes 色彩](https://www.radix-ui.com/themes/docs/theme/color)：采用有色中性灰和成对明暗色阶；强调色、文字和表面按职责管理。
- [Radix 色阶职责](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)：背景、交互状态、边线、实色、文字分层。调整后的自定义色值须重算对比，不能继承原色阶的保证。
- [Fluent 2 色彩](https://fluent2.microsoft.design/color)：中性表面建立层次，品牌色控制占比，危险/成功等语义颜色用于状态。
- [Fluent 2 材质](https://fluent2.microsoft.design/material)：不透明表面支撑阅读和交互，半透明只用于合适的层；这里用 CSS 表面近似质感，不声称获得原生 Mica / Acrylic。
- [Material 3 颜色职责](https://m3.material.io/styles/color/the-color-system)：成对考虑容器与其上的文字，并区分表面、强调和边线。
- [Radix 字体](https://www.radix-ui.com/themes/docs/theme/typography)：字号、行高、字重和系统字体构成一致阅读层级。本主题保留 Codex 用户字体设定，主要统一颜色职责。
