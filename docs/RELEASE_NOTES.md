# 龙娘工坊 v0.1.0-beta.2

两个静态聊天背景版本：Q 版双姿态与正常立绘左大右小。人物位于原生聊天内容后方，保留克制的明暗双主题、原生字体、输入几何和菜单。构图灵感来自 DSH Maid Atelier。

本版经过一次授权的 Opus 设计评审并在本机复核：增强浅色人物细节、降低中央渐变强度、拉开立绘大小、限制 Q 图放大。底色保持低亮度，完整取舍见 docs/DESIGN_REVIEW.md。

验证：Windows Store Codex 26.1002.6548.0、Node 24.16.0。两版本各自的深浅首页、输入不发送、模型菜单、恢复，以及真实会话滚轮均通过；每版 16 类场景回归和配色检查通过。其他平台 / 版本 / 缩放 / 多显示器和长期运行未完整验收。

使用：下载 Windows ZIP，核对 SHA256SUMS.txt。需要 Node.js 22+；先保存原生主题分享码，导入 ZIP 内深浅分享码，再运行“启动Q版背景.cmd”或“启动立绘背景.cmd”。独立配置窗口可能需要重新登录；“恢复装饰.cmd”移除本项目装饰。

启动器能重新打开关闭后仍保留后台 renderer 的同配置窗口；哈希计算改用 .NET SHA256，兼容 WinPS 中 Get-FileHash 无法解析的环境。另提供“记录窗口遮挡.cmd”与严格按安装路径及 PID 创建时间匹配的“解除开屏遮挡.cmd”。历史开屏卡死原因尚未确认，这些工具不代表已彻底修复该故障。

保留 Dynamic Skin Manager 1.6.2 运行时文件遗漏的源补丁，未重编译其 EXE。
