# 设计评审与实现取舍

2026-10-07，对 Q 版 / 正常立绘版各自的深浅实机匿名截图、项目需求和 CSS / 配色做了一次授权评审。复用本机既有 Wawazz 的 Anthropic messages 链路，请求与返回的模型标识均为 `claude-opus-5-5`；HTTP 200、完整 end_turn。服务返回的标识不能独立证明底层模型身份。

原始请求、认证调用脚本和完整响应都不进入仓库与发行包。没有外发私人聊天、故障日志或本机配置；凭据仅用于认证。

## 采纳的方向

- 增强浅色人物线条、通过左右不同透明度建立主次。
- 正常立绘首页拉开大小：宽度上限为聊天列 42% / 26%，同时约束各自高度和原图宽高比。当前实机首页为 399 / 247px；会话退让后不承诺恒定 1.6:1 比例。
- 中央渐变最大背景混合由 65% 降到 50%，20–40% / 60–80% 为两侧过渡。原实现已有渐变，评审所称“硬边界”不作为已证实的代码问题。
- 深色面板改为 #26272f、边线 #53515f；浅色边线 #b0a8bc，改善表面层级。

## 保留与修正

用户要求降低整体亮度，因此保留原底色 #1b1c23 / #e8e7ed，没有采用全面提亮浅色到近白的建议。所有原生字体、字号、几何布局、菜单层级和状态色保持由原生客户端负责，不新增水印控件或网络字体。

Q 帧仅有 192×208，首页 / 会话最大宽度改为 280 / 240px，减少放大模糊。原图集不修改；这不是高分辨率重制，仍受素材本身分辨率限制。

评审建议的宽度 CSS 示例遗漏了人物宽高比，实际仍通过现有 renderer 计算尺寸，没有直接复制示例。评审给出的对比度为估算，实施后在本地重新计算。

## 配色实算与验收界限

按 sRGB 相对亮度计算；正文和次要文字取 background / panel / panelAlt 三种定义阅读表面中的最低值。

| 模式 | 正文最低 | 次要文字最低 | 焦点对面板 |
|---|---|---|---|
| 深色 | 10.295:1 | 5.945:1 | 6.569:1 |
| 浅色 | 9.121:1 | 4.662:1 | 5.353:1 |

这不是整个客户端的无障碍认证。装饰边线未声明 3:1，每个原生控件、人物后面的实际像素仍需按使用情境检查。

最终改动后重新做了两版本、两模式的真实首页截图 / 输入不发送 / 原生模型菜单 / 恢复，以及实际会话鼠标滚轮。场景回归覆盖窄列、侧面板挤占、菜单层级、缺失节点降级、点击穿透和空闲无持续重绘。原生控件没有因人物增加新桌面窗口；未来 Codex 升级及其他平台仍需重新验证，见 [完整记录](VALIDATION.md)。
