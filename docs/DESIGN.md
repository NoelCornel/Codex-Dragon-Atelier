# 配色与适配

使用低亮度炭灰 / 雾灰底色、低饱和紫作为强调色、少量旧金色装饰。白发、灰角、淡紫瞳与原角色的白色龙尾保持可辨认。同一角色的待机与挥手姿态分居两侧，不额外创造第二位角色身份。

配色的职责划分参考 Material 3 的表面、文字、强调色设计：
https://m3.material.io/styles/color/the-color-system 。排版参考其清晰的层级原则：https://m3.material.io/styles/typography/applying-type 。字体继续采用 Codex 原生配置，避免中文回退、字重和许可问题。

原生主题码负责大部分颜色；可见的语义节点负责局部装饰。监听原生 computed color-scheme，而非假设旧版 electron-dark 类一定存在。新版缓存旧路由时仅选取可见节点。角色不覆盖正文/输入区，空间不足时隐藏。状态、diff 和语法配色沿用独立语义角色。

场景和调色仅作用于本项目标记节点；移除时恢复先前属性。设置页不启用；系统高对比度隐藏装饰。减少动画时采用上游原始图集的静态首帧。无需修改受保护的客户端安装文件。
