# 原生窗口遮挡取证

如果切换到其他应用后，屏幕同一片区域仍然点不动，先运行“记录窗口遮挡.cmd”。它记录可见原生窗口的矩形、置顶状态、Hung 标志、进程及鼠标下窗口句柄；输出在 `evidence/window-snapshots/`，含本机路径，不要直接公开。

“解除开屏遮挡.cmd”先记录快照，再仅结束安装于本项目同级 `tools/DragonCodexBoot/DragonCodexBoot.exe` 的开屏播放器。PID、可执行路径和创建时间必须匹配。该工具不结束 Codex 或其他程序。其他安装布局只记录，不会误杀其他播放器。

开屏源码包含不显示在任务栏的置顶窗口及 DWM 预览。预览在交接前不能代替真实客户端交互；超时若运行于同一 UI 线程，也不能保证处理该线程的卡住。仅凭这一设计不能证明某次历史故障由它造成，必须结合现场窗口记录。

本主题入口直接启动 Microsoft Store 官方客户端，角色舞台仅属于该客户端内的聊天区域。不会为主题创建原生置顶覆盖窗。
