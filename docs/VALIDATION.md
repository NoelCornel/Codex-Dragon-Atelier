2026-10-07，Windows Store Codex 26.1002.6548.0，Node 24.16.0。首版记录作为历史范围保留在后半部分。

## 本次真实客户端

- Q 版与正常立绘版首页：原生深/浅两主题，聊天底层舞台、各两个人物、132 个空间命中点均不由舞台接收点击；截图已逐张人工查看并匿名化。
- 两版输入区与移除装饰后的几何差异小于 1px；实际输入测试字再清空、不发送；原生模型菜单打开和关闭、恢复均通过。
- 评审改动后重新检查：Q 版和正常立绘版各自的深浅两种首页、输入、原生模型菜单、恢复，以及真实会话滚轮均通过。当前真实会话识别 thread、各显示两个人物，不发送消息。
- 当前客户端聊天列采用 flex-col-reverse，scrollTop 可为负数；测试按真实滚轮行为核对，未把正向 scrollTop 赋值无变化误判为冻结。
- PowerShell 5.1 启动 -> PowerShell 7 恢复，以及 7 启动 -> 5.1 恢复均通过；身份时间比较兼容 JSON 日期自动转换。切换版型核对 PID、路径及创建时间，只结束自己的观察进程。
- 最终中文 CMD 入口检查发现当前 WinPS 环境无法解析 Get-FileHash。哈希计算已改为 .NET SHA256，避免依赖该模块函数，不修改系统模块路径；随后重新执行启动入口。
- 测试窗口关闭时，后台 CDP 和 renderer 仍存在，动画帧停止。重复打开同一测试配置恢复了窗口和自动点击，未改变窗口尺寸。启动器已加入同配置重新打开处理；不是历史桌面遮挡的复现。
- 当前运行版型为正常立绘版，保留原生明暗选择与字体。未验证全新账号首次登录或未来客户端升级。

## 自动检查与素材

- 每版 16 类浏览器行为回归通过：自动明暗、语义状态色、窄列/侧面板挤占退让、聊天内 z0 舞台、菜单层级、边缘控件点击、静态不同姿态、空闲无持续重绘、缓存旧路由、会话背景、减少动态效果、inert、缺失锚点、未知定位主区域降级、恢复。
- 3 项配色测试通过，并独立重算最终色值、核对 CSS 与 tokens 一致。深色正文/次要文字在定义表面最低 10.295 / 5.945，浅色最低 9.121 / 4.662；焦点色对面板 6.569 / 5.353。装饰边线不声明满足 3:1；未据此声称每个实际像素或全部原生控件已逐一测量。
- Q 原始图集字节未变；正常立绘原图与透明成品均有来源、尺寸、SHA256。透明成品 RGBA、四角 alpha=0，白色人物区域保持不透明填色；做了背景处理，不声称像素完全一致。
- 构建和包装使用明确白名单，私有 evidence、用户配置和认证材料不进入包。

# v0.1.0-beta.1 验证记录

验证日期：2026-10-07。平台：Windows、Microsoft Store Codex **26.1002.6548.0**；Node **24.16.0**。

## 真实客户端

- 官方深色、浅色分享码均通过真实外观导入界面接受，颜色在客户端实际生效。
- 首页两种主题均显示双姿态，输入区边界与移除装饰后的原生边界差异小于 1px。
- 实际输入测试文字并清除，没有发送消息；模型选择菜单可打开和关闭，装饰不拦截点击。
- 当前会话页识别为 thread，留白不足时安全隐藏角色；输入区仍可操作。程序尝试扩大窗口后该会话留白未变化，**不将其视为宽窗口双角色实机验收**。
- 重复应用只保留一个场景和一个样式节点；移除装饰不改变原生明暗设置。
- 本机观察进程启动、停止、恢复和重新启动通过。已存在的本机 CDP 客户端连接已验证；全新用户配置首次登录体验尚未完整验收。
- 公共截图来自真实客户端，侧栏、项目名通过临时遮盖匿名化，未更改聊天资料。

## 自动检查

- 3 项配色测试：深浅两套的正文和次要文字在全部定义阅读表面达到 4.5:1，焦点色与背景达到 3:1；限制浅色整体亮度。
- 浏览器模拟回归：自动明暗切换、原生状态色、窄窗隐藏、缓存旧路由、会话留白、减少动画、不可交互装饰、缺失锚点降级、恢复，共 9 类行为。
- 模拟页面的宽会话双角色测试通过，不能替代真实宽会话验收。
- 素材 Git blob 与固定上游提交对应，文件不经重新编码。

## 管理器打包修复

上游 1.6.2 资源遗漏回归在原文件上 1/5 通过，修复后 5/5 通过；连同相邻相关检查共 11/11，通过 Windows EngineOnly 检查。本机已补齐提取缓存中缺少的 11 个运行时文件，实际 `injector.mjs --check-payload` 通过。
