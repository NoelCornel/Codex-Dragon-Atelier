当前 Store Codex 26.1002.6548.0，Node 24.16.0，实际 DPR1.25。以下为功能与限定场景验证，不代表用户已认可全部审美。

- 原生明暗分享码真实导入；Q/正常立绘两版、深浅两模式首页、输入测试字并清空、不发送、模型菜单、移除均核对。输入几何变化小于 1px，装饰不命中 132 个实际空间点。
- 真实占位符伪元素 opacity:1；圆角/实体色/轮廓位于内框，外框透明且无阴影；编辑器字体家族、字号、字重、行高前后相同。侧栏普通文字实际为不透明正文色，排除局部 nav 派生半透明变量。

- 最新预览临时替换文本节点后恢复，保留真实字体/表面/控件，逐张查看；匿名原始 API 请求、配置、账户资料、故障日志均不进入仓库或包。

Opus 补充评审：授权项目 CSS、色表、匿名截图；首次长回复 max_tokens，A–G保留，第二次仅补齐H且正常 end_turn。原文已合并保存《可读性与双角色实施指导》。返回模型标识不能独立证明底层身份；边界对比度、CSS选择器、素材像素及用户审美反馈均由本地再次核验。

## 未验证范围

本轮滚轮检查曾因固定500ms等待失败。关闭主题的对照同样出现延迟，最终原生/有主题均能滚动；一次CDP输入及观察序列总用时约6.0s/5.1s，包含协议与调用等待，不等于纯用户界面延迟测量。后续验收逐次读取实际位移，避开嵌套工具输出滚动区；功能检查不证明不存在性能问题，也不证明历史桌面遮挡已修复。
