# v0.1.0-beta.1 验证记录

验证日期：2026-10-07。平台：Windows、Microsoft Store Codex **26.1002.6548.0**；Node **24.16.0**。

## 真实客户端

- 官方深色、浅色分享码均通过真实外观导入界面接受，颜色在客户端实际生效。
- 首页两种主题均显示双姿态，输入区边界与移除装饰后的原生边界差异小于 1px。
- 实际输入测试文字并清除，没有发送消息；模型选择菜单可打开和关闭，装饰不拦截点击。
- 当前会话页识别为 thread，留白不足时安全隐藏角色；输入区仍可操作。程序尝试扩大窗口后该会话留白未变化，**不将其视为宽窗口双角色实机验收**。
- 重复应用只保留一个场景和一个样式节点；移除装饰不改变原生明暗设置。
- 本机观察进程启动、停止、恢复和重新启动通过。已存在的本机 CDP 客户端连接已验证；全新用户配置首次登录体验尚未完整验收。
- 公共截图来自真实客户端，侧栏、项目名通过临时遮盖匿名化，未更改聊天资料。

## 自动检查

- 3 项配色测试：深浅两套的正文和次要文字在全部定义阅读表面达到 4.5:1，焦点色与背景达到 3:1；限制浅色整体亮度。
- 浏览器模拟回归：自动明暗切换、原生状态色、窄窗隐藏、缓存旧路由、会话留白、减少动画、不可交互装饰、缺失锚点降级、恢复，共 9 类行为。
- 模拟页面的宽会话双角色测试通过，不能替代真实宽会话验收。
- 素材 Git blob 与固定上游提交对应，文件不经重新编码。

## 管理器打包修复

上游 1.6.2 资源遗漏回归在原文件上 1/5 通过，修复后 5/5 通过；连同相邻相关检查共 11/11，通过 Windows EngineOnly 检查。本机已补齐提取缓存中缺少的 11 个运行时文件，实际 `injector.mjs --check-payload` 通过。

本机只有 .NET Runtime，没有 SDK，**未重编译或验收管理器 EXE**。公开交付是源补丁；官方 1.6.2 原 EXE 的全新安装仍需要上游修复。

## 未验证范围

macOS、Linux、其他 Codex 版本、不同缩放比例、多显示器、跨客户端升级、宽会话的实机双角色显示。新版本优先使用原生配色；角色节点不匹配时自动关闭。发布为 Beta，不承诺全版本兼容。
